# Modee Creative — Organic Skincare

Design system for the Modee Creative organic-skincare web shop.

- `design-system/README.md` — brand book (content, visual foundations, iconography)
- `design-system/tokens.json` — colour, type, spacing, radius, shadow and tracking tokens
- `design-system/components/` — 12 React components (`bundle.js` exposes `window.ModeeSkincare`), each with a README and live `preview.html`

## Website
`index.html` is the Modee Creative home, Shop and Cart pages (served by GitHub Pages). It runs with `support.js` and `image-slot.js` and loads React from unpkg, so it needs an internet connection. Photos are in `images/`.
